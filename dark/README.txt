Dark-mode versions of the CRM Lottie icons (103 files, same file names as the originals).
Designed for a dark card background of #212529.

Recolor rules
- Navy outlines/fills (#405189)  -> soft light lavender (#C7CEF5)
- White fills/cut-out strokes     -> card color #212529 (so the white blobs disappear but overlaps still hide lines behind them)
- Light gray / lilac / pink fills -> darker tones so they no longer glow
- Red accents                     -> brighter red (#FF6363)
- Lordicon colour controls (primary/secondary) recolored the same way
Animation, timing and shapes are untouched; only colors changed.
